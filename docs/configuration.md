# Technical configuration

`configs/model.json` contains known model information and accepted solver tolerances: DOP853 rtol=1e-10, atol=1e-12; boundary-value tol=1e-9, max_nodes=50000. Gaussian X0 uses standard deviation sqrt(.01), not .01. No terminal cost is present. Linear interpolation and Euler–Maruyama state updates are retained.

`configs/development.json` records the exact30 candidates, datasets1000–1019, K1000,4096 paths per endpoint, h=.0001, initial lambda=.5, seed0, checkpoints[0,250,500,750,1000], generating settings and strict ordered selection. `configs/scientific.json` is the compact approved-grid/common-K metadata checked against that configuration. `configs/unseen.json` records the ten frozen eta values in the README and the same training settings. Output `config.json` files preserve exact experiment specifications for report-only reconstruction.

Observation rounds use SeedSequence([20260818,1,dataset_id,round_index]), rounds0–99, with200 agents per round and100 rounds. Synthetic lambda_star=.9 is generation/recovery information only. Training banks use SeedSequence([20261016,dataset_id,0,zero_based_iteration]); both FD endpoints and all configurations at matching dataset/iteration share exogenous randomness. Later iterations use fresh banks. Known initial moments remain fixed; empirical initial means are not substituted or recentered.

Each NPZ contains time, empirical_mean, observed state/action square means, J_left,sJ,Q, observation_count=20000, dataset seed and observation settings. These are sufficient statistics, not full trajectories. `load_expert` exposes only the immutable mean/J summary and its derived scales. J_E=.001*sum(.5*(state_second+action_second+empirical_mean**2)[:-1]); sJ=J_E**2 and Q=trapezoid(empirical_mean**2,time).

Development selection is strictly within each family: require20 valid completed runs; maximize count with abs(error)<=.01; sequentially filter MAE/RMSE/MaxAE within1e-4 of the surviving minima; minimize total projections, then median tail sample SD, then eta. Full selection traces and deciding steps remain in selection.csv. The archival status column records the original proposal stage; the eta values were subsequently accepted and frozen.

For unseen family f, w_f(M)=2.58*SD_f(M), with sample SD ddof=1 and SE=SD/sqrt(M) separately reported. Relative change is abs(w_f(M)-w_f(M-5))/max(w_f(M-5),1e-12); Delta(M)=max_f change. Minimum M40, batch5 and two consecutive Delta<=.05 checks are required. The historical design’s cap200/ID universe remains recorded in the exact configuration. The public frozen runner caps actual exposure at the accepted40 IDs and raises a discrepancy if M40 does not satisfy stopping; it never continues to unused reserved IDs.

Figures map to canonical accepted presentations: altruism=Figure1 cumulative1-mean(lambda)±2.58 sample SD; recovery=Figure2 every individual fixed40 estimate; beta_recovery=Figure3 nine V1 families at frozen eta, all40 estimates and mean±1 sample SD, full/magnified views; cumulative_recovery=Supplementary1; stopping=Supplementary2. Those full historical searches and exploratory K2000 studies are intentionally excluded. The included development/unseen implementation and compact evidence were independently reproduced without changing scientific kernels.
